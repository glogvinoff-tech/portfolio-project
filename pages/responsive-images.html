Адаптивные изображения

Демонстрация современных техник работы с изображениями

Art Direction

Разные изображения для разных размеров экрана с помощью picture элемента

<picture>
  <source media="(min-width: 1200px)" srcset="wide-desktop.jpg">
  <source media="(min-width: 768px)" srcset="tablet.jpg">
  <img src="mobile.jpg" alt="..." class="responsive-image">
</picture>

Что происходит:

  • Десктопы (1200px+): загружается wide-desktop.jpg
  • Планшеты (768px-1199px): загружается tablet.jpg
  • Мобильные (до 767px): загружается mobile.jpg
  • Браузер автоматически выбирает подходящее изображение

Resolution Switching

Поддержка Retina и HiDPI экранов с помощью srcset

<img src="icon@1x.png"
    srcset="icon@1x.png 1x, icon@2x.png 2x"
    alt="..." class="retina-image">

Что происходит:

  • Обычные экраны: загружается icon@1x.png
  • Retina экраны: автоматически загружается icon@2x.png (в 2 раза четче)
  • Автоматическое определение плотности пикселей устройства

Современные форматы

Использование AVIF и WebP с fallback для старых браузеров

<picture>
  <source type="image/avif" srcset="portrait.avif">
  <source type="image/webp" srcset="portrait.webp">
  <img src="portrait.jpg" alt="..." class="responsive-image">
</picture>

Что происходит:

  • Современные браузеры: выбирают AVIF (лучшее сжатие)
  • Браузеры с поддержкой WebP: выбирают WebP
  • Старые браузеры: загружают JPEG fallback
  • Автоматическое переключение между форматами

Object-fit свойства

Контроль заполнения контейнера изображением с помощью object-fit

object-fit: cover

Заполняет контейнер, обрезая края

object-fit: contain

Вписывает полностью, могут быть поля

/* Cover - заполняет с обрезкой */
.object-fit-cover { object-fit: cover; }

/* Contain - вписывает полностью */
.object-fit-contain { object-fit: contain; }

Lazy Loading

Оптимизация загрузки с помощью loading="lazy"

<img src="image.jpg" alt="..." loading="lazy">

Что происходит:

  • Изображение загружается только когда приближается к viewport
  • Уменьшает начальный размер страницы
  • Улучшает производительность загрузки
  • Особенно полезно для длинных страниц с многими изображениями
